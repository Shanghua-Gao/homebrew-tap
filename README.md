# Homebrew tap for RSI-Jev

```sh
brew install shanghua-gao/tap/decideit
```

Installs `decide`, `decideit` and `agentguard` from [RSI-Jev](https://github.com/Shanghua-Gao/RSI-Jev). It needs an Apple Silicon Mac running macOS 14 or newer. The bundle brings its own Python, so you don't install anything first. The model (about 1.7 GB) downloads the first time you run `decide`.

```sh
git diff | decide "Does this change touch authentication?"
```

See the [Mac guide](https://github.com/Shanghua-Gao/RSI-Jev/blob/main/docs/mac.md).
